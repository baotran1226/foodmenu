# FOOD MENU - PWA

`index.html` vẫn là trang đầu tiên của project.

## Chạy trên GitHub Pages

Upload toàn bộ nội dung thư mục này lên repository và bật GitHub Pages.

## Cài trên iPhone

1. Mở website bằng Safari.
2. Nhấn nút Chia sẻ.
3. Chọn "Thêm vào Màn hình chính".
4. Nhấn "Thêm".

App sẽ mở ở chế độ standalone như một ứng dụng.

## Lưu ý

Dữ liệu món ăn hiện dùng `localStorage`, vì vậy dữ liệu thêm/sửa/xóa được lưu riêng trên từng thiết bị và không đồng bộ giữa các điện thoại.
